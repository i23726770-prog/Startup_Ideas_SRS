## База данных

Для хранения информации о пользователях, идеях стартапов и планах их реализации разработана реляционная база данных.

База данных состоит из восьми таблиц:
- Users — пользователи.
- Ideas — идеи стартапов.
- Categories — категории идей.
- Statuses — статусы идей.
- Priorities — приоритеты идей.
- Plans — планы реализации.
- PlanGoals — цели планов.
- PlanStages — этапы планов.

### Файлы базы данных

- database/schema.sql — структура базы данных.
- database/seed_data.sql — тестовые данные.
- database/normalization.md — описание нормализации до третьей нормальной формы (3НФ).
